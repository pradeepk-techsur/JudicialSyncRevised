Research already performed during planning (do not re-derive, just apply):
- `@carbon/react` (current latest ^1.118.x), `@carbon/styles` (^1.117.x), `@carbon/icons-react` (^11.90.x) all declare React 19 in their peerDependencies — compatible with this project's react@19.3.0, no `--legacy-peer-deps` needed. Re-verify exact current versions with `npm view @carbon/react version` / `npm view @carbon/styles version` / `npm view @carbon/icons-react version` at execution time (pin to whatever is current then, per this project's "verify-don't-guess" convention — do NOT hardcode the versions found during planning if a newer patch/minor has shipped since).
- `sass` (Dart Sass) is a required devDependency — `@carbon/react` needs it to compile; Next.js has built-in `.scss` support once `sass` is installed, no webpack config needed.
- Carbon's own official Next.js example (`carbon-design-system/carbon` repo, `examples/nextjs/`) uses this exact pattern — treat it as the authoritative reference:
  - `next.config.ts`: `sassOptions: { quietDeps: true }` (suppresses noisy deprecation warnings from Carbon's own internal Sass, not fatal otherwise).
  - A single Sass entry point imported from the root layout: `@use '@carbon/react/scss/reset'; @use '@carbon/react/scss/grid'; @use '@carbon/react/scss/layer'; @use '@carbon/react/scss/themes'; @use '@carbon/react/scss/theme';` or, simpler for an app with many disparate components (this project's case — 33 files across 9 screen areas), `@use '@carbon/react';` which pulls in ALL component styles at once. Use the simpler all-in-one `@use '@carbon/react';` form — hand-picking per-component Sass imports is the right call for a design-system library shipping its OWN bundle size budget, not for a single internal demo app undergoing a full-surface migration in one phase.
  - No dark-mode theme switch exists in the current app (no toggle in the UI) and none is being added — do NOT call `@include theme.theme(themes.$g100)` anywhere. Carbon's default (no explicit theme call) is the White theme, which is the light theme already in use — this preserves current visual treatment without a feature addition.
