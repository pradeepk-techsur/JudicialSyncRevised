Carbon component notes verified during planning:
- `Tag` supports a polymorphic `as`/rendered-element pattern and an `onClick`-driven interactive mode (renders as `<button>` when clickable) — exactly what `CitationPill` needs: a clickable, bordered, small pill. Since the pill must navigate (not just fire a client handler), render it with Next.js's `<Link>` as the Tag's underlying element (Carbon's `Tag` accepts an `as` prop per its polymorphic typing — `<Tag as={Link} href={...}>`), falling back to wrapping a plain `<Tag>` inside a `<Link>` if the installed version's `as` prop doesn't compose cleanly with `next/link`'s own prop contract (verify at execution time; both approaches preserve "real `<a>` in the tab order," which Y2-accessibility.md requires — "Citation pills are real `<a>`/button elements in the DOM tab order, never a styled `<span>`").
- `InlineNotification` (`kind="warning"`) is the correct Carbon component for the "assistant temporarily unavailable" system notice — it is semantically and visually distinct from `MessageBubble`, satisfying the "error channel, never a decline" requirement structurally (different component entirely, not just a different CSS class on the same bubble component).
- Carbon's `Loading` component (`small` variant, or the three-dot `InlineLoading` variant) replaces the hand-rolled `animate-pulse` three-dot typing indicator.
- Carbon has no literal "chat bubble" component — `MessageBubble`'s bubble shape stays a custom CSS Module (Carbon's `Tile` is a reasonable base for the assistant's bubble if its default padding/border looks right, or a bare styled `<div>` using Carbon's color/spacing/radius tokens directly — either is acceptable; this is explicitly a "Carbon doesn't dictate everything" case, same as the Timeline/AssistantPanel slide-over).
- The slide-over panel (`AssistantPanel.tsx`) is explicitly NOT a modal — per Y0-patterns and the Screen-04 mockup, the underlying screen stays visible and a citation click routes the underlying screen while the panel stays open. Do NOT reach for Carbon's `Modal`/`ComposedModal` (those trap focus and block background interaction by design) — keep the custom CSS-Module-driven translate-on/off slide-over container, restyled with Carbon tokens (shadow/border/spacing) but structurally unchanged.
