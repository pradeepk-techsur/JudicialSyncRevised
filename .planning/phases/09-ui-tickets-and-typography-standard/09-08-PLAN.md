<objective>
Fix the sidebar's weak active-nav feedback and the Jury Package badge's count mismatch (T-08 from the external UI/UX review): give the current route's nav item a clear active treatment (background + bar + icon, per Carbon's `SideNavLink` `isActive` prop) and change the Jury Package badge to count what the Jury Package page's own Blockers section actually shows, instead of the case-wide open-discrepancy count (which can include discrepancies on exhibits never in any jury package at all).

Purpose: a route-aware active state is a basic navigation affordance this app never implemented, and a sidebar number that disagrees with the page it links to erodes trust in every other number in the product.
Output: a visibly active nav item with icons, and a Jury Package badge count that always matches the page.
</objective>
