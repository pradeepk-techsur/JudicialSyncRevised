<objective>
Make `StatusBadge`'s internal status→color map the single EXPORTED source of truth (T-03 from the external UI/UX review), so `StatusDistributionBar`'s hand-authored duplicate color map is deleted and replaced with a direct import — eliminating the drift risk the ticket names ("Objected is yellow in the legend, cyan in the Case Workspace pill") even though both currently happen to already agree on `OBJECTED`'s color by coincidence (a second hand-copied map, not a shared source, is the actual defect being fixed).

Purpose: a status's color must be defined in exactly one place so it is structurally impossible for two screens to diverge, and add icons so status is never communicated by color alone.
Output: one exported `STATUS_CONFIG`, `StatusDistributionBar` consuming it directly, and a cross-screen parity test.
</objective>
